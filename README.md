# Breast Cancer Prediction 

Predicting breast cancer (Malignant/Benign) using Neural Networks.

## Model
Artificial Neural Network (ANN) — TensorFlow/Keras

## Results
| Metric | Score |
|--------|-------|
| Accuracy | 93.86% |
| Loss | 0.1973 |

## Dataset
- sklearn Wisconsin Breast Cancer Dataset
- 569 samples, 30 features
- Binary classification: Malignant (0) / Benign (1)
